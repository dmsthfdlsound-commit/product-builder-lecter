## 2. 게임별 반복 불만 (커뮤니티 리서치)

레딧·팬덤 포럼·부모 가이드·뉴스·틱톡 커뮤니티에서 **반복적으로** 제기되는 불만만 수집 (일회성 불평 제외).

### 2-1. 소셜/롤플레이/클래식 군

**Brookhaven RP** (2위)
- 🔞 온라인 데이팅(ODer)·부적절한 성적 RP — 부모·커뮤니티 최다 불만. 오픈 샌드박스 구조라 만연
- 🛡️ 모더레이션 공백·그루밍 위험 — Bloomberg 탐사보도가 상징적 사례. 신고해도 조치가 안 보인다는 불만 다수
- 😴 목적 없는 얕은 게임플레이 — "NPC처럼 채팅만 한다", "퀄리티 낮은데 1위" 비판 상존
- 💸 Voldex 인수(2025.2) 후 과금 강화 우려 — 차량/집/옷이 프리미엄 게임패스 뒤로
- 🔊 익스플로잇 — 필터 우회 폭음 오디오(boombox) 반복 문제

**Adopt Me!** (17위권)
- 🎣 아동 대상 트레이드 사기 — 썸네일 사기, "믿고 먼저 주기", 크로스 트레이딩. 위키에 사기 유형 분류표가 있을 정도
- 💸 비싼 과금 — 펫 1개 1,000~1,500 R$, VIP 인상, Pets+ 구독($2.99/월). 부모들 "애가 $100~300 결제" 사례 보도
- 🎰 알(에그) = 루트박스 — 영국/호주 규제 이슈로 랜덤 부화를 고정 순서로 바꾸자 이번엔 "노잼 그라인드" 역불만
- 🪦 정체성 상실 — "가족 RP 게임이 트레이딩 시뮬레이터가 됐다"는 고인물 이탈
- 🤖 신규 펫 "AI 슬롭" 논란 + 개발진 소통 부재 불만

**Dress to Impress** (13위)
- 🗳️ 투표 조작·악성 투표 — 자기 등수 올리려 전원 별점 테러, 스타 품앗이 "파밍 서버", 그룹챗 담합
- 🧑🏿‍🦱 차별 투표 — 어두운 피부톤 아바타가 옷과 무관하게 저평가된다는 반복 보고 (틱톡 대형 이슈)
- 🔞 저연령층 대상 성인화된 의상/포즈 — Change.org 청원까지 존재. 외모 평가 루프의 바디이미지 우려
- 😡 커뮤니티 독성화 — 라운드 종료 공개 평가가 사이버불링으로. 크리에이터 밴 드라마 반복
- 💸 VIP 페이월 — 경쟁 게임인데 주 $2.99 패스 전용 아이템 ~96종
- 📢 레이디 가가 이벤트 허위광고 논란 — 인플루언서만 실제 참여, 일반 유저는 중계 시청. 공식 사과

**Murder Mystery 2** (16위권)
- 🎣 사기 경제 — 가짜 중개인, 막판 아이템 스왑, 시세 모르는 뉴비 등치기("sharking"). 공식 중개/거래 롤백 없음
- 👾 핵 유저 방치 — 에임봇/ESP 신고해도 조치 없다는 불만이 수년째
- 🏜️ 업데이트 가뭄 — 시즌 아이템 외 콘텐츠 정체, "개발자가 의욕을 잃었다" 논쟁, 경제까지 침체
- 💸 P2W 루트박스 — 갓리 나이프가 유료 미스터리 박스에서, 이벤트 재화도 R$로 구매 가능해 배틀패스 무의미화
- 🤝 팀밍·캠핑 — 친구/형제끼리 짜고 치기, 보안관 총 캠핑으로 라운드 공정성 붕괴
- 📊 시세표 이원화 — 커뮤니티 시세 리스트 2개가 서로 달라 뉴비가 손해 보는 구조

**Pls Donate** (20위권)
- 🙏 구걸 문화 — 기부하면 따라다니며 조르는 유저들, "e-begging 플랫폼" 비판
- 🎣 기부 사기 — "10 주면 20 돌려줄게" 더블링 사기, 짝퉁 기부 게임, 조작된 진열대. 위키에 전용 사기 문서 존재
- 🚨 그루밍 벡터 — 거액 기부 후 "빚"으로 프레이밍해 디스코드/스냅챗으로 유인하는 패턴 문서화
- 💥 2026년 5월 로블록스 크로스게임 판매 금지로 핵심 메커니즘 붕괴 — 기부에 사실상 Roblox Plus 구독 필요해져 "Pls Donate는 끝났다" 여론

### 2-2. 생존/호러/스킬 군

**99 Nights in the Forest** (5위)
- 😤 팀원 그리핑 — 공용 캠프의 음식/도끼/전리품을 랜덤 팀원이 훔쳐감. "내 물건 가져가는 팀원" 자체가 틱톡 콘텐츠 장르가 될 정도
- 🧒 랜덤 스쿼드의 독성 — 부활 안 해줬다고 분노, 트롤링, 자원 독점
- 💸 셀프 부활 = 로벅스 — 팀원은 메드킷으로 살려도 자기 부활은 사실상 과금. 다이아(재능 뽑기 재화)도 최대 2,500 R$ 팩 판매
- 🔁 세션 저장 없음 — 나가거나 튕기면 생존자·기지·아이템 전부 증발
- 😴 novelty가 꺼지면 단조로운 루프 — "지루하다/과대평가" 여론 반복

**Fish It! / Fisch** (10위)
- 💸 공격적 페이월 — 로비부터 영구 행운 부스트/VIP/보트 게임패스 도배. "가장 탐욕스러운 로블록스 게임" 폭로 영상까지
- 🎲 **스트리머 행운 조작 스캔들** — 스트리머·특정 유저에게 몰래 행운 버프를 준 사실이 드러나 신뢰 붕괴
- 🎰 시크릿 물고기 = 중첩 RNG 게이트 — 행운 스택 없이는 사실상 불가능한 확률 설계
- 🤖 AFK 매크로 메타 — 24시간 자동낚시가 정상화되어 명당 독점 + 서버 랙, "정직한 낚시가 무의미"
- 💾 데이터 손실/롤백 + 트레이드 중단 (Fisch) — 수십 시간 그라인드가 안전하지 않다는 인식

**Doors** (19위)
- 📈 Floor 2 난이도 스파이크 — "반응 불가능한" 즉사 구간들, "형언할 수 없이 불공평" 원성
- 💸 부활 = 로벅스 — 죽으면 Door 1부터. 안정적 부활 수단은 사실상 과금뿐(5회 ~120 R$)이라 "실패를 수익화한다" 비판
- 🪙 보상 경제 빈약 — 최고 난이도 구간이 쉬운 호텔과 같은 기본 보상(50 knobs)
- 🐌 히트박스·랙·입력 지연 사망 — 특히 모바일/저사양에서 "내 잘못이 아닌 죽음"
- 🏜️ 업데이트 가뭄 — Floor 3 수년째 대기

**Tower of Hell** (18위)
- 😈 서버 전체 그리핑 — 아무나 서버 전원에게 적용되는 디버프 뮤테이터를 구매 가능 → 라운드 시작마다 트롤이 안개/저속 걸어버림
- 🕊️ 플라이 핵 만연 — 꼭대기까지 날아가 정상 유저 조롱. 안티치트가 못 따라감
- 🪜 체크포인트 없음 — 한 번 실수 = 바닥부터. 8분 타이머와 겹쳐 분노 유발
- 💸 구매형 어드밴티지 — 시간 부스트/기어 구매 유저와의 경쟁 불만, 기어는 라운드마다 재구매

**Jailbreak** (20위)
- 👮 경찰 캠핑 — 은행/보석상 출구와 감옥 스폰에서 체포 농사. "camping cops"가 커뮤니티 은어로 굳음
- 💸 P2W — 로벅스 차량/VIP 패스/시즌 스킵 구매자의 명백한 우위
- 📋 지루한 시즌 계약 그라인드 — 내 잘못 아닌 실패가 가능한 계약 설계, 레벨 50까지 긴 XP 노가다
- 🔫 익스플로잇 — noclip/에임봇이 강도·추격전 반복 붕괴
- 🔁 9년 된 루프 노후화 — "업데이트가 코어를 못 바꾼다"

### 2-3. 전투/그라인드 시뮬 군

**Blox Fruits** (8위)
- ⛏️ 극단적 반복 그라인드 — 만렙 2650+, 업데이트마다 재노가다. "게임이 아니라 일 같다"는 이탈 사유 1위
- 🩸 저렙 사냥하는 바운티 헌터 — 퀘스트 중인 뉴비를 만렙이 학살+"ez" 도발. 가이드가 "프라이빗 서버가 유일한 피난처"라고 공식화
- 💸 P2W 게임패스 — 2x 머니/마스터리, 1,200 R$ 다크 블레이드, 2,700 R$ 과일 알림기. "게임이 만든 고통을 과금으로 판다"
- 🎣 트레이드 사기 만연 — 막판 스왑, 가짜 중개인. 서드파티 사기 방지 가이드 생태계가 존재할 정도
- 🏜️ 업데이트 가뭄 — 한 번에 10개월까지 벌어진 공백

**The Strongest Battlegrounds** (9위)
- ☠️ 커뮤니티 독성 최상급 — 타겟팅 괴롭힘, 킬스틸, "ez" 스팸. 캐주얼 유저가 설 곳 없음
- 👥 솔로 대상 팀밍 — 무리 지어 혼자 온 유저 집단 구타. 공식 대응책 없음("너도 팀을 만들어라")
- 👾 핵 유저 — 플라이/킬오라/텔레포트킬. 로블록스 신고는 무반응, 신고가 개발자 디스코드로 떠넘겨짐
- 🏜️ 업데이트 공백 — 공언한 2~3주 주기가 상습적으로 한 달+
- ⚖️ 스팸 가능한 밸런스 붕괴 무브셋 + 특전 캐릭터의 접근 제한

**Blade Ball** (15위)
- 🤖 오토패리 핵 — 타이밍 패리가 게임의 전부인데 스크립트가 그걸 무력화. 가장 많이 문서화된 문제
- 🎰 상자 가챠 — 최상급 스킨 ~0.1%. 부모 대상 리뷰에서 "gambling-lite" 규정
- 💸 P2W 어빌리티 — Infinity(자동 디플렉트) 논란으로 경쟁 밸런스 붕괴 비판
- 🐌 랙 = 죽음 — 밀리초 단위 판정이라 핑 스파이크가 곧 억울한 사망
- 🎣 공식 시세 없음 → 가짜 시세 커뮤니티가 사기 수단화

**Pet Simulator 99** (14위)
- 🎰 알 부화 = 슬롯머신 — Huge/Titanic 천문학적 확률, 확률 스텔스 너프 백래시(1/9.99억→1/1000억 주장)까지
- 💸 "Forever Pack" — 무료로 시작해 점점 커지는 결제 유도. "플랫폼에서 가장 약탈적인 과금 장치" 평
- 🤖 게임을 안 하는 게 최적해 — 오토클리커+밤샘 AFK가 메타. "게임으론 mid, 도파민 주입기로는 elite"
- 🎣 펫 스위치 사기 + eBay 현금 암시장
- 📉 신규 펫 홍수로 기존 컬렉션 가치 폭락 — "경제가 영구히 망가졌다"

**Toilet Tower Defense** (톱20 경계권)
- 💸 업데이트마다 신규 유료 유닛(399~699 R$) — "현금몰이에 집중하다 재미를 잊었다"
- 🎰 크레이트 가챠 미식 확률 (~0.1% 미만)
- 📈 파워 크리프 극단 — 적 HP 1억+, 신규 유닛이 구 유닛 즉시 무가치화
- 🎣 가짜 트레이드 익스플로잇 + 신뢰 사기
- 🪦 "TTD는 죽었다" — 원본 밈과의 괴리 + 업데이트 피로로 동접 급감
