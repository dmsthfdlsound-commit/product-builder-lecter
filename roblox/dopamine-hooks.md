# 🧨 안달 엔진 10 — 도파민을 한 단계 더 끌어올리는 훅 설계

> 전제: 도파민은 보상 순간이 아니라 **"올 것 같은" 순간**에 최대로 분비됩니다 (기대 도파민 > 획득 도파민).
> 그래서 이 문서의 훅들은 전부 "보상을 키우는" 게 아니라 **"기다림·긴장·궁금함을 설계"**합니다.
> 원칙 유지: 갈망은 게임플레이에서 나오게 하고, 지갑 압박에서 나오게 하지 않는다 — 그게 우리 차별화([top20 분석](./top20-complaints-opportunity.md) 참조)이자 규제/부모 리스크 헤지.

## 훅 카탈로그

### 1. 🔔 예고된 잭팟 — "3분 뒤 황금떡이 컨베이어에 등장합니다"
- **심리**: 기대 도파민. 복권은 긁는 순간보다 사서 기다리는 동안이 달콤함
- **메커니즘**: 레어 등급이 컨베이어에 뜨기 전, 서버 전체에 예고 방송 + 카운트다운. 전 서버 유저가 컨베이어 앞으로 모여들고, 등장 순간 구매 경쟁(선착순 or 경매 3초)
- **안달 포인트**: 예고~등장 사이 3분간 아무것도 안 일어나는데 아무도 못 떠남. 놓치면 "다음 예고"를 기다리게 됨
- **구현**: 서버 스크립트 타이머 + 방송 UI. 난이도 하

### 2. 🌡️ 천장 카운터를 긴장 장치로 — "보장까지 3회"
- **심리**: 목표 근접 효과(goal gradient) — 결승선이 보이면 멈출 수 없음
- **메커니즘**: 확률 공개+천장(이미 설계됨)의 카운터를 단순 숫자가 아니라 **차오르는 게이지**로. 잔여 5회부터 게이지가 달아오르는 연출, 잔여 1회는 화면 전체가 예열
- **안달 포인트**: "천장 2번 남기고 로그아웃"이 불가능해짐. 정직한 확률로 슬롯머신급 긴장을 만드는 합법 장치
- **주의**: 가짜 니어미스(꽝인데 아슬아슬해 보이는 연출 조작)는 금지 — 신뢰·규제 리스크. 긴장은 **진짜 정보**(실제 카운터)로만
- **구현**: 가챠 시스템에 카운터 1개 추가. 난이도 하

### 3. 📺 서버 전광판 — 남의 잭팟이 내 도파민
- **심리**: 사회적 증명 + 부러움. 카지노가 잭팟 사이렌을 전체에 울리는 이유
- **메커니즘**: 서버 상공 전광판에 실시간 티커 — "XX님이 황금떡 획득!!" + 그 유저 머리 위 10초 왕관 이펙트. 레전더리급은 서버 전체 화면 플래시
- **안달 포인트**: 남이 뽑는 걸 보면 나도 뽑고 싶다. 얻은 사람은 과시 도파민, 본 사람은 갈망 도파민 — 한 이벤트로 2인분
- **구현**: RemoteEvent 방송 + 빌보드 UI. 난이도 하

### 4. 🏪 개장 스트릭 — 가게가 식는 게 보인다
- **심리**: 손실 회피. 단, 실제 자산을 깎으면 원한(이탈)이 되므로 **연출만 깎는다**
- **메커니즘**: 매일 접속해 10분 영업하면 "단골 게이지" 유지 — 단골이 많을수록 가게 앞 NPC 줄이 길어지고 활기참. 끊기면 자산 손실은 0이지만 가게가 눈에 띄게 한산해짐(NPC 줄 소멸, 불 꺼진 간판). 복귀 첫 영업으로 즉시 복구
- **안달 포인트**: "오늘 안 들어가면 가게가 식는다"는 이미지가 머리에 남음. 잃는 건 없는데 잃는 기분 — 소프트 스트릭
- **구현**: 로그인 기록 + NPC 스폰 수 연동. 난이도 중

### 5. 🚨 "그놈이 접속했다" — 복수 알림
- **심리**: 미완결 과제(자이가르닉 효과) + 복수 동기. 미해결 드라마는 잊히지 않음
- **메커니즘**: 내 물건을 훔쳐간 도둑이 온라인이 되면 인게임 알림 + 광장에 그놈의 지명수배 포스터 점등. 잡으면(훔쳐 되찾거나 현상금 처치) "정의 구현" 리플레이 클립 자동 생성 → 원버튼 공유
- **안달 포인트**: 하던 걸 멈추고 달려가게 만드는 인터럽트. 복수 성공 클립은 틱톡 바이럴 소재(마케팅 자가발전)
- **구현**: 도난 로그 + Players 이벤트 + 클립은 후순위. 난이도 중

### 6. 🧩 도감의 빈칸 — 마지막 1개의 저주
- **심리**: 자이가르닉 + 수집 완결 욕구. 9/10은 0/10보다 훨씬 고통스럽다
- **메커니즘**: 컬렉션 도감에서 미보유 칸이 실루엣+"???"로 표시. 세트(예: 분식 오리지널 8종) 완성 시 가게 외관 진화 + 명예 칭호. 세트 보너스는 치장/명예형(수익형 아님 — 파워크리프 방지 원칙 유지)
- **안달 포인트**: 7/8에서 멈춘 도감은 매일 쳐다보게 됨. 남의 완성된 가게 외관이 걸어다니는 광고
- **구현**: 도감 UI + 조건부 외관 스왑. 난이도 중

### 7. 🌧️ 상태 한정 이벤트 — 언제 올지 모르는 개이득
- **심리**: 변동 간격 강화(variable interval) — 랜덤 타이밍 보상은 확인 행동을 만든다 (슬롯머신을 시간축으로 옮긴 것)
- **메커니즘**: 서버 날씨/상황 시스템 — 비 오면 어묵 수요 3배, 한파엔 붕어빵 러시, 랜덤 등장 "황금 손님"은 아무 레어템이나 시세 5배에 사감. 예고 없음, 접속 중이면 개이득
- **안달 포인트**: FOMO의 순기능만 — 정해진 시각(Admin Abuse류 원성)이 아니라 랜덤이라 "혹시 지금?" 하고 들어와 봄. 놓쳐도 소외감이 아니라 "다음엔 잡는다"
- **구현**: 서버 이벤트 루프 + 배수 파라미터. 난이도 하

### 8. 🔥 더블 오어 낫싱 화덕 — 스스로 선택한 긴장
- **심리**: 선택한 리스크는 강요된 리스크와 달리 원한이 안 남는다. 긴장의 소유권을 유저에게
- **메커니즘**: 수확물을 화덕에 "한 번 더 굽기" — 성공(60%) 시 가치 2배·윤기 이펙트, 실패 시 "탄 떡"이 되는데 **탄 떡도 수집품**(도감에 탄 것 카테고리, 밈 아이템·전시 가능). 연속 성공 시 배수 상승, 언제든 스톱 가능
- **안달 포인트**: "한 번만 더"의 심리를 시스템화. 실패조차 콘텐츠(웃긴 탄 떡 도감)라 분노 대신 웃음 — KALB 쓰나미(보상 삭제)의 정반대
- **구현**: 확률 + 아이템 상태 변환. 난이도 하

### 9. 🏃 장물 가치 실시간 상승 — 들고 튀는 맛
- **심리**: 상승 중 정지 결정(눈덩이를 언제 멈출까) — 러너 게임의 코인 배수와 동일
- **메커니즘**: 남의 아이템을 훔쳐 들고 도망치는 동안 장물 가치가 초당 상승(최대 2배). 내 기지에 골인해야 확정, 잡히면 원소유자에게 반환+내 현상금 상승. 오래 들고 다닐수록 이득이지만 전 서버에 내 위치 핑이 점점 자주 찍힘
- **안달 포인트**: 도둑도 쫓는 자도 심박수 상승. "지금 골인할까 10초 더 끌까"의 매 순간이 마이크로 도박(정직한)
- **구현**: 상태 머신 + 위치 핑 방송. 난이도 중

### 10. 🎁 부재중 하이라이트 릴 — 재접속이 미니 잭팟
- **심리**: 궁금함은 가장 싼 재접속 트리거. "없는 동안 무슨 일이?"
- **메커니즘**: 접속하면 10초 리캡 — 쌓인 수익 카운트업, 가게에 왔다 간 유명 손님, **막아낸 도둑 시도**(방어 성공 연출), 친구가 남긴 노크/스티커. 마지막에 "오늘의 예보"(내 가게에 유리한 상태 이벤트 힌트)
- **안달 포인트**: 로그인 자체가 보상 오프닝이 됨 + 예보가 오늘의 목표를 심어줌. 오프라인 습격이 없는 우리 설계에서 "부재중 서사"를 대신 공급
- **구현**: 이벤트 로그 저장 + 리캡 UI. 난이도 중

## 지키는 선 (안달 ≠ 약탈)

1. **가짜 니어미스 금지** — 연출은 화려하게, 확률 조작처럼 보이는 트릭은 금지 (Fish It 행운 조작 스캔들의 교훈)
2. **스트릭은 연출만 깎는다** — 실자산 박탈형 스트릭은 원한 → 이탈
3. **랜덤 이벤트는 보너스, 필수템 아님** — 놓친 사람이 영구 손해 보는 구조 금지 (Admin Abuse 반면교사)
4. **모든 긴장은 유저가 선택한 리스크에서** — 화덕·장물 배수는 옵트인, 강제 긴장은 훔치기 방어뿐(보험 있음)
5. 위 4개 선이 무너지면 부모 가이드 사이트 평가가 뒤집힘 — 우리 유통 전략 자체가 붕괴
