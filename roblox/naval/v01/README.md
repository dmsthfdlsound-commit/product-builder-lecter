# ⚓ 해상전 v0.1 «포격전» — 첫 게임 형태

> 스파이크 ①②(세트 트릭·포격) 위에 **해도(스테이지 선택) + 난이도 3종 + 별 평가 + 은화/저장**을 얹은 빌드.
> **`build/NavalV01.rbxlx` 더블클릭 → F5**. (저장 테스트는 Game Settings → Security → API Services 활성화)

## 게임 플로우

해도에서 스테이지 선택 → 3초 출항 카운트다운 → 포격전 → 격침 시 ⭐ 평가·🪙 은화 → 해도로.
패배(침몰)는 손실 0 — 해도에서 재도전. 이전 스테이지 ⭐1 이상이 다음 스테이지 잠금 해제 조건.

## 스테이지

| # | 이름 | 난이도 | 적 HP (돛/선체/갑판) | 일제사격 | 🪙 | ⭐3 보너스 조건 |
|---|---|---|---|---|---|---|
| 1 | 연안 밀수선 | ★ | 200/400/150 | 70dmg · 10~13s | 120 | 90초 내 격침 |
| 2 | 호송 스쿠너 | ★★ | 300/600/250 | 95dmg · 8~11s | 260 | 돛+갑판 완파 후 격침 |
| 3 | 사략 브리간틴 | ★★★ | 400/850/350 | 120dmg · 7~9s | 520 | 퍼펙트 브레이스 5회 |

⭐ 계산: ①승리 ②아군 선체 75% 이상 유지 ③스테이지별 보너스. 최고 기록만 저장(DataStore).

## v0.1이 검증하는 것

- 스테이지 반복 루프가 "한 판 더"를 만드는가 (별 3개 수집 욕구 = 도감 빈칸 훅의 스테이지판)
- 난이도 곡선: S1 입문(여유) → S2 부위 전략 강제(보너스가 돛+갑판 완파) → S3 브레이스 숙련 요구
- 은화 누적이 다음 목표(추후 선체/모듈 상점)의 기반이 되는가

## 🛠️ 조선소 (은화 사용처)

해도 화면의 조선소 버튼 → 3계통 × 3티어 (서버 권위 구매·저장):

| 계통 | 효과 | 비용 |
|---|---|---|
| 💥 포문 확장 | 일제사격 4→5→6→7발 | 300 / 800 / 1,800 |
| 🛡️ 장갑판 | 피격 100→88→78→70% (접속자 중 최고 티어 적용 = 협동 보너스) | 250 / 700 / 1,600 |
| 🎯 조준 보조 | 산포 9.0→7.25→5.5→3.75 | 200 / 600 / 1,400 |

성능은 은화(플레이)로만 산다 — 치장만 로벅스 원칙 유지. 이로써 **스테이지 → 별·은화 → 강화 → 다음 스테이지** 루프가 닫힘.

## ⚡ 2막 — 총격전 (통합됨)

적 선체가 50% 이하로 붕괴하면 **적함이 330→120스터드로 접근**하며 2막 전환:

- 무기가 선회포로 교체 (단발 · 재장전 1.2초 · 대인 특화: 갑판 40 / 선체 25 / 돛 15)
- **갈고리 러시**: 4~7초마다 적이 갈고리를 던짐 — 우현 난간에 빨간 훅 등장, 2.6초 안에 클릭/탭 or 🪓 절단 버튼. 실패 시 선체 −120
- 선원을 저격할수록 적 일제사격이 약해지고(화력 반감 규칙 연동), 선체를 마저 부수면 격침

즉 1막의 부위 선택이 2막 난이도를 결정합니다 — 기획의 캐리오버 구조가 두 막에 걸쳐 실동작.

## 🪝 3막 — 백병전 (통합됨: 3막 풀 사이클 완성)

2막에서 적 선체가 25% 이하로 떨어지면 **도선 분기**: 적함이 현측 접현(X≈39)하고 널판 2개가 걸린다.

- 커틀러스(인벤토리 1번) 장착 → 널판 건너 적 갑판으로 → 적 선원 4명 소탕
- 선원 AI는 휴머노이드 없는 CFrame 스테퍼 — 밀림/플링 물리 리스크 0
- **나포 승리 = 은화 ×1.5** (격침보다 크다 — "빨리 끝내기 vs 크게 벌기" 선택 구조)
- 1·2막에서 선체를 0까지 부수면 여전히 조기 격침(×1.0) 가능
