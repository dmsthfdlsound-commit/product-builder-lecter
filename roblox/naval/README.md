## 프로젝트 히스토리

1. **오픈월드 항해 기획** (초안) → 적대적 검증 3렌즈 전원 경고 (엔진 블로커 13개, 일정 3~5배 낙관, "항해는 지루하다")
2. **스테이지형 피벗** (사용자 결정) — 배는 장비, 해전은 1:1 PvE 스테이지, 거리 3막(원→중→근) 진행
3. `design.md` v1 — 피벗 구조에 리서치·설계 수치 이식, 검증 처방 반영 완료
