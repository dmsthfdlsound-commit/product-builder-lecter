# ⚓ 해상전 스파이크 v0 — 세트 트릭 + 1막 포격전

> [design.md](../design.md) §7의 Week 0 스파이크 ①(세트 트릭)과 ②(포격 손맛)를 하나의 플레이 가능한 빌드로 검증.
> **`build/NavalSpike.rbxlx` 더블클릭 → F5** 로 즉시 실행.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 이동 / 화면 터치 | 적함 조준 — 조준점이 부위별 색으로 표시 (⛵돛=하늘 / 🛡️선체=주황 / 👥갑판=빨강) |
| 💥 버튼 or **F** | 일제사격 (4문, 재장전 6초) |
| 🛡️ 버튼 or **G** | 브레이스 — 적 포문이 빨갛게 빛나면 1초 안에! (착탄 직전 0.4초 = PERFECT −80%) |

## 이 스파이크가 검증하는 것 (판정 기준)

1. **세트 트릭** — 갑판은 월드에 완전 고정. 바다가 오르내리고, 포말이 흘러가고, 적함이 흔들리고, 카메라가 미세하게 스웨이. → **"배 위에 있는 것 같은가?"** (5인 중 4인 YES = PASS)
2. **포격 손맛** — 조준→발사→탄도 비행→착탄 이펙트→피해 플로터. → **"한 판 더 쏘고 싶은가?"**
3. **부위 전략이 읽히는가** — 기획의 심장인 캐리오버 규칙 2개가 실제 동작:
   - ⛵ 돛 완파 → **적 재장전 +60%** (일제사격 간격 8~11초 → 13~17초)
   - 👥 갑판(선원 4명) 제압 → **적 화력 −50%**
   - 🛡️ 선체 0 → **격침** (돛/갑판 상태가 격침 배너에 보너스로 표기)
4. **브레이스 타이밍** — 1초 경고(포문 발광+경보음+빨간 비네트) → G/버튼. 퍼펙트 창 0.4초(모바일 검증 반영값)

패배해도 손실 0 (구조→5초 후 재도전). 격침 시 아군 선체 +400 수리. 2인 접속 시 협동 자동 동작(선체 공유, 브레이스는 최고 등급 적용).

## 아키텍처 노트 (스파이크 전용 지름길 포함)

- **서버**: 정적 월드 생성 + 전투 권위 전부 (발사 레이캐스트 판정·부위 HP·일제사격 스케줄·브레이스 등급) — 본편 원칙 유지
- **클라이언트**: 세트 트릭 연출 전담 — 바다/포말/적함 흔들림은 `GetServerTimeNow()` 기반이라 모든 클라이언트가 같은 장면을 봄
- ⚠️ 지름길 1: 적함 흔들림이 클라 연출이라 서버 판정은 정지 자세 기준 (오차 ~1.5스터드, 스파이크에선 허용)
- ⚠️ 지름길 2: 사운드는 내장 에셋 2종의 피치 변형 — 본편에서 실제 포성/파도 SFX로 교체 필수
- 파트 수: 씬 전체 ~90개 (모바일 예산의 2%) — 저가폰 여유 큼
