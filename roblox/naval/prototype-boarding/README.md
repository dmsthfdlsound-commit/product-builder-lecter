## 조작

| 입력 | 동작 |
|---|---|
| 인벤토리 1번 (커틀러스 장착) 후 클릭/탭 | 베기 (전방 10스터드, 120° 아크, 35 피해) — Tool이라 **모바일 버튼 자동 생성** |
| 이동 | 널판을 건너 적함으로 |

## 승리 경로 2개 (기획의 목표전 구조 검증)

1. **⚔️ 소탕**: 적 선원 5명 전원 처치
2. **🎡 점거**: 적함 후미 조타륜 근처에 10초 서 있기 (이탈 시 게이지 서서히 감소) — 싸움을 피하고 기동으로 이기는 경로

적 선원은 플레이어보다 느리게(9.5 vs 16) 추격 + 근접 공격(12 피해/1.4초) — 카이팅 가능하게 설계. 사망해도 손실 0, 리스폰 후 재도전. 승리 시 리더보드 "나포" +1, 8초 후 새 라운드.

## 이 스파이크가 검증하는 것

1. **앵커 갑판 위 근접 전투가 성립하는가** — NPC는 휴머노이드 없는 서버 CFrame 스테퍼(15Hz)라 물리 리스크 0. 밀림/플링 없음
2. **널판 도선** — 고정된 두 함선 사이를 걸어서 건너는 동선이 자연스러운가
3. **목표전 구조** — "전부 죽이기 vs 점거" 양자택일이 실제로 다른 플레이를 만드는가
4. **모바일 검격** — Tool 기반이라 터치 버튼 공짜. 판정(전방 아크)은 서버

## 스파이크 지름길 (본편에서 교체)

- NPC 애니메이션 없음 (블록+머리) → 본편은 장식 리그 or 경량 커스텀 리그
- 검격 애니메이션은 기본 Slash 훅(`toolanim`) — 본편은 커스텀 애니메이션
- 사운드 내장 에셋 2종 피치 변형
- NPC가 갑판 경계를 지오메트리로만 신뢰 (본편은 항행 가능 영역 마스크)
