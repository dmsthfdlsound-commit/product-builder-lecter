드래그한 사각형 안의 자모를 전부 사용해 단어를 만들 수 있으면 사라집니다. 순서는 상관없습니다.

ㅜ ㅁ ㄹ → 물
  • 제한 시간은 2분. 지운 자모 수만큼 점수가 오릅니다.
  • 긴 단어일수록 보너스가 큽니다. 3자모는 3점, 6자모는 12점.
  • 3초 안에 이어서 지우면 콤보가 쌓입니다. 배점이 ×1.5 → ×2 → ×2.5 → 최대 ×3까지 오릅니다.
  • 지워진 칸은 빈칸으로 남습니다. 다음 사각형은 빈칸을 건너뛰고 묶을 수 있습니다.
  • 복합 모음은 쪼개져 있습니다. ㅏ + ㅣ = ㅐ, ㅗ + ㅏ = ㅘ, ㄱ + ㄱ = ㄲ.
