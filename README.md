# 로또 번호 생성기 (Lotto 6/45)

배포·수익화 준비가 끝난 무료 로또 번호 생성 웹앱입니다. 프레임워크 없이 순수 HTML/CSS/JS로 만들어져 정적 호스팅(GitHub Pages, Firebase Hosting 등) 어디서나 바로 동작합니다.

## 기능

- 1~5게임 동시 생성 (동행복권 공식 볼 색상)
- 완전 랜덤 / 홀짝·구간 균형 모드
- 고정수·제외수 지정
- 번호 저장(localStorage), 복사, 공유(Web Share API)
- 모바일 반응형, SEO 메타태그, 광고 슬롯 내장

## 실행

정적 파일이므로 `index.html`을 열거나 아무 정적 서버로 서빙하면 됩니다.

```bash
npx serve .
```

## 자모 사과게임 (`/jamo`)

같은 저장소에 들어 있는 두 번째 웹앱입니다. 사과게임 형식의 한글 단어 퍼즐로,
드래그한 사각형 안의 자모를 **순서 상관없이** 전부 써서 단어를 만들면 사라집니다 (`ㅜ ㅁ ㄹ` → 물).

- 2분 타이머, 긴 단어일수록 커지는 점수 보너스, 힌트 3회
- **콤보** — 3초 안에 이어서 지우면 배점이 최대 ×3까지 오릅니다
- 남은 시간에 따라 조여드는 타이머 바, 마지막 10초 카운트다운 연출, 효과음(끌 수 있음)
- **쉬움 모드** — 만들 수 있는 단어가 판 아래에 다 적혀 있고, 지울 때마다 사라집니다
- 매일 자정(KST)에 바뀌는 **오늘의 판** — 서버 없이 날짜 시드로 모두가 같은 판을 풉니다
- 최고 점수·연속 출석 저장, 결과 공유 텍스트

```bash
npx serve .   # → http://localhost:3000/jamo/
```
